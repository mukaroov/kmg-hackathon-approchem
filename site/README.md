# STRATA · фронтенд «Глава → курс»

Сайт, который превращает загруженную главу книги в курс и ведёт по нему ученика с личным рангом.

**Два режима.** Открытый с сервера STRATA (`http://адрес:8000/`) — вход по почте и паролю, курсы, проверка ответов, прогресс и помощник идут через API, данные в базе (см. `../README.md`). Открытый как файл или без сервера — офлайн-режим ниже: всё в браузере, без регистрации. Режим выбирает `js/api.js` автоматически.

## Как открыть

Откройте `index.html` в браузере. Или запустите локальный сервер из этой папки:

```
python -m http.server 8080
```

и откройте `http://localhost:8080`. Прогресс хранится в браузере; при открытии через файл и через сервер браузер использует разные хранилища.

## Опыт и ранги

Опыт начисляется только за три вещи:

| За что | XP |
| --- | ---: |
| Шаг завершён: решены все его задания | 50 |
| Все задания шага верно с первой попытки | 30 |
| Серия: первый завершённый шаг за день, 10 × число дней подряд (до 7) | 10–70 |

Уровень n требует 100·n·(n−1)/2 опыта. Ранги по уровню: Новичок (1), Стажёр (3), Специалист (5), Эксперт (8), Мастер (11), Грандмастер (15). Правила в одном месте: `js/xp.js` → `RULES`, `RANKS`.

## Как собирается курс без сервера

`js/engine.js` (версия `local-rules-1.0`) работает только с текстом автора и не выдумывает:

- режет книгу по меткам страниц и по выбранным заголовкам, потому что первая и последняя страницы главы обычно содержат соседние разделы;
- делит главу на единицы покрытия (абзац, заголовок, таблица, формула, рисунок, пример, задача) и строит таблицу «единица → шаг или причина» в формате `coverage.schema.json`;
- собирает части и шаги по заголовкам, длинные разделы делит на части;
- строит задания четырёх типов из предложений книги, у каждого есть страница и цитата;
- делает карточки на все шаги и термины и граф связей «термин введён → используется дальше»;
- помечает фрагменты, где кириллица распознана латиницей;
- отделяет описания рисунков, которые при распознавании дописала модель (блоки «━━━ FORMAT N …», в главах организаторов это 11–35 % текста). Они показываются свёрнутыми с меткой «модель» и не попадают в задания и термины.

Блоки «Частая ошибка», «Что это значит для данных», «Аналогия» и расчётные задания требуют модели. Без сервера они скрыты.

Проверено на главах организаторов. Латышова, гл. V, стр. 90–108, границы §17 и §21: 16 шагов, 41 задание четырёх типов, все задачи книги 86–108 и все примеры 46–55, 11 описаний рисунков моделью, покрытие 184 из 184 единиц. Кузнецов, гл. 10, стр. 200–222: 13 шагов, 36 заданий, 12 описаний моделью, покрытие 141 из 141.

## Подключение бэкенда

Всё в `js/api.js`. Адрес сервера и включение задаются на странице «Профиль и настройки». Пути API (`PATHS`) — предложенные контракты из `STRATA_ANALYSIS/08_BACKEND_INTEGRATION_REQUIREMENTS.md`, напарник подтверждает или меняет их в одном месте:

- `POST /pipeline/runs` — книга (в том числе PDF) уходит на серверный конвейер, сервер возвращает курс в той же модели, что и локальный движок (`js/catalog.js`, комментарий в начале файла);
- `POST /events/batch` — события обучения с уникальным `id`; очередь хранится локально и отправляется повторно, сервер убирает дубли;
- `POST /tutor/hint` — подсказка модели с опорой на страницу; без сервера работают локальные подсказки.

Секретов во фронтенде нет; ключи моделей и авторизация — на сервере.

## Данные и совместимость

- Прогресс: `localStorage['strata-v2']`; старый профиль `strata-profile-v1` переносится автоматически, прежние ответы засчитываются.
- Загруженные книги и курсы: IndexedDB `strata` (хранилища `courses`, `books`); исходный текст сохраняется для пересборки.
- Событие ответа: `type, courseId, lessonId, questionId, taskType, correct, response, elapsed` (активное время, с), `idle` (простой, с), `changes` (смены ответа), `hints`, `attempt`, `ts`, `id`.
- Без внешних библиотек, шрифтов и запросов в интернет; размер сайта около 4 МБ.
