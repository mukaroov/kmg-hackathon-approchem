## Модели

| Этап | Модель | Версия | Где работает | Что уходит наружу | Как заменить |
| --- | --- | --- | --- | --- | --- |
| Распознавание PDF | Mistral OCR | алиас `mistral-ocr-latest`; фактическая версия пишется в журнал задачи | облако Mistral (API `/v1/ocr`) | страницы PDF главы; для md-входа — ничего | переменная `OCR_MODEL` в `.env`; без OCR — загрузить md главы |
| Описание рисунков из PDF | Mistral Medium 3.5 | `mistral-medium-2604` | облако Mistral (`/v1/chat/completions`) | изображения рисунков главы | `LLM_VISION_MODEL`; выключить — `DESCRIBE_FIGURES=0` |
| Учебный слой: план шагов, узлы, маршрутизация | Mistral Medium 3.5 (Large ключу недоступна) | `mistral-medium-2604` | облако Mistral | текст главы (md) и промпты `pipeline/prompts/` | `LLM_MODEL` и `LLM_PROVIDER` в `.env`; любой API, совместимый с OpenAI Chat Completions (`LLM_PROVIDER=openai-compatible`, `LLM_BASE_URL`) |
| Курс и задания | та же модель, что для слоя (задания пишутся в запросе узла и добираются отдельным запросом) | — | облако Mistral | текст страниц шага | `LLM_MODEL` |
| Модуль проверки | детерминированные проверки (цитаты, страницы, числа, покрытие, схемы) + смысловая проверка той же моделью | — | проверки — локально; смысловая — облако Mistral | текст шага и страниц | `LLM_MODEL`; выключить смысловую проверку — `VERIFY=0` |
| Слой без API (режим `agent`) | агент, отвечающий на запросы из `work/agent-queue/` (главы Кузнецова и Басниева: Claude, Anthropic) | записывается в `layer/<глава>/pipeline-run.json` | там, где работает агент | промпты конвейера с текстом страниц главы — агенту | `LLM_PROVIDER=agent`/`cli`, `LLM_CLI`, `LLM_CLI_MODEL` |
| Спецификация сцены ролика | та же модель, что для слоя | — | как у слоя | текст шага и схема движка | `LLM_MODEL` / режим agent |
| Модуль проверки внешнего пакета | сверка — локально; суждение — та же модель | — | как у слоя | элементы пакета, страницы главы, кадры PNG (в режиме agent — путь к файлу) | `node pipeline/review.mjs` |
| Сборка курса | без модели | — | локально | ничего | — |
| Озвучка | Gemini TTS `gemini-3.8-flash-tts`, голос Charon; запасные — Fish Audio `s2.1-pro-free`, Windows SAPI «Microsoft Irina Desktop» (`pipeline/lib/tts.mjs`) | gemini-3.8-flash-tts | Gemini API / локально | текст реплик сценария (Gemini, Fish); ничего (Windows) | `TTS_PROVIDER`, `GEMINI_TTS_VOICE`, `GEMINI_TTS_STYLE`, `FISH_VOICE` |
| Иллюстрации и кадры роликов | без генеративных моделей: рисунки строятся кодом (виджеты `engine/widgets.js`), кадры — детерминированным движком `video/video_engine.py` | — | локально | ничего | — |

Выход данных во внешний сервис: текст и страницы глав уходят в Mistral AI (La Plateforme). Ключ — бесплатный план Experiment. Использование запросов для обучения моделей Mistral выключено в консоли (Admin Console → Privacy). Тесты конвейера без внешних вызовов: `LLM_PROVIDER=stub` (заглушка, наружу ничего не уходит).

Повторный прогон той же главы с теми же настройками берёт ответы из кеша `cache/llm/` и наружу ничего не отправляет.

## Запуск

Одна команда на главу:

```
node pipeline/run.mjs <глава.md|глава.pdf> [--pages 90-108] [--page-start N] [--id имя]
```

Ролик к шагу: `node pipeline/video.mjs layer/<глава> <id шага> [--format 9:16|16:9]`. Модуль проверки: `node pipeline/review.mjs <package.json>`.

Сервер API для фронтенда: `node pipeline/server.mjs` (контракт — `pipeline/API.md`). Пересборка курса после правки слоя: `node build/build.mjs layer/<глава>`.

Учёт: токены и деньги по этапам — `logs/metrics.csv` (пишет конвейер). Ручные правки — `logs/manual_edits.csv` (ведёт команда). Отчёт каждого прогона — `work/jobs/<id>/report.json`.
