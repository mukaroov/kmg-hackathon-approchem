# Произношение обозначений и аббревиатур (домен drilling)

Собрано по главе test_basarygin.md. Этап видео заменяет обозначение в тексте озвучки на колонку «Читается»; субтитры остаются как в сценарии.

## Обозначения и аббревиатуры

| Обозначение | Читается |
| --- | --- |
| ГНВП | гэ эн вэ пэ |
| АВПД | а вэ пэ дэ |
| СПО | эс пэ о |
| p_{заб} | пэ забойное |
| p_{пл} | пэ пластовое |
| ΔV_{min} | дельта вэ минимальное |
| ε | эпсилон |
| S | эс |
| ΔQ_{min} | дельта ку минимальное |
| δ | дельта |
| Q_{max} | ку максимальное |
| ρ_{0} | ро нулевое |
| ρ_{гр} | ро газированного раствора |
| ρ_{ф} | ро флюида |
| l_{ф} | эль флюида |
| Δp | дельта пэ |
| a_{0} | а нулевое |
| v_{п} | вэ механическое |
| л/с | литров в секунду |
| м³ | кубических метров |
| м² | квадратных метров |
| МПа | мегапаскаль |
| % | процентов |
| НКТ | эн ка тэ |
| g | же |
