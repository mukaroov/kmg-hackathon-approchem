# Доменный пакет `geo`: геология и геофизика нефтегаза

Движок конвейера (`pipeline/`, `build/`, `video/video_engine.py`) геологии не знает: всё предметное лежит здесь и подключается по имени пакета (`--domain geo`, поле `domain` в `chapter.json`). Для нового домена (например, бурения) копируется структура этой папки и заполняется заново; код не меняется.

| Файл | Что внутри | Кто читает |
| --- | --- | --- |
| `domain.json` | Имя домена, читатель, правила нотации, подсказки для модели, 8 типов трудности, ссылки на файлы пакета, шаблоны сцен по типам трудности (`sceneTemplates`) | все промпты конвейера (`pipeline/prompts/system.md`), этап видео |
| `glossary.md` | Термины RU/EN с определением и местом в главе | собирается `node tools/domain-collect.mjs` из слоёв |
| `misconceptions.json` | Заблуждения `misc.*` (заготовка организаторов) | узлы (`mistake.ref`), этап связей, неверные варианты заданий |
| `physics_checklist.json` | Чек-лист корректности `pc.*` (заготовка организаторов) | спецификация сцены, паспорт ролика |
| `it_bridges.md` | ИТ-аналогии и где они ломаются | собирается `node tools/domain-collect.mjs` из слоёв |
| `styleguide.json` | Стайлгайд организаторов: цвета пород, флюидов, кривых, метки происхождения | источник для `video_style.json` и `legend.json` |
| `video_style.json` | Стиль кадров движка: цвета, минимальный размер подписей, безопасные поля | `video/video_engine.py` |
| `legend.json` | Легенда цветов курса | сборщик курса |
| `pronunciation.md` | Как читать аббревиатуры и обозначения (заготовка организаторов + термины глав) | этап видео: текст озвучки перед синтезом |
| `stress_dictionary.md` | Ударения в терминах (U+0301) | этап видео при `TTS_STRESS=1` |

Листы опечаток распознавания по главам хранятся в слое главы (`chapter.json → errata`), а не в пакете: они относятся к книге, а не к домену.

## Шаблоны сцен по типам трудности

| Тип | Шаблоны движка |
| --- | --- |
| М механизм | `pressure_wave_2d`, `formula_dynamic_plot` |
| В геологическое время | `geological_evolution` |
| И косвенное измерение | `well_log_sync`, `crossplot_cutoff` |
| Ф формализм | `formula_dynamic_plot`, `pressure_wave_2d` |
| П пространство | `geological_evolution`, `pressure_wave_2d` |
| Пр процедура | `well_log_sync` |
| Н неопределённость и решение | `crossplot_cutoff` |
| Р распознавание | `well_log_sync`, `crossplot_cutoff` |

Шаблоны без изменений подошли для обучающих глав Кузнецова (`geological_evolution`, шортс) и Басниева (`pressure_wave_2d`: в движок добавлен режим постоянного дебита). Для бурения из этого набора ожидаемо подходят `formula_dynamic_plot` (гидростатика, давление в стволе) и `pressure_wave_2d`; газ в стволе и конструкция скважины потребуют нового шаблона.

## Время сборки пакета

Пакет `geo` собран из заготовок организаторов за ~1 час работы агента: заготовки скопированы, словарь произношений дополнен 11 обозначениями глав, ударения — 5 словами, глоссарий (183 термина) и ИТ-мосты (51) собраны скриптом из слоёв.
