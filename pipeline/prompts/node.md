{{outline}}

{{units}}

Текст страниц {{pages}} с метками страниц (единицы шага лежат здесь; остальное — контекст):
{{text}}

Заполни поля:
- title (3–7 слов), bookTitle, bookShort (до 6 слов).
- essence: 2–3 фразы, первая — главное.
- how: абзацы «как это работает» по порядку автора; у каждого page и claims — id утверждений, на которые он опирается. Покрой каждую мысль, условие и оговорку из единиц шага.
- claims: утверждения с дословными цитатами (правило 3). id — c1, c2, …. kind — observation / inference / assumption. sourceKind — text / formula / table / figure_caption. text — утверждение своими словами, не сильнее цитаты: не обобщай, не теряй условий, не меняй знак.
- procedure: если автор даёт порядок действий — intro, page и items; иначе items пустой.
- examples: каждый разобранный пример автора из единиц шага — id (ex1, ex2…), title («Пример N»), page, given, steps (по шагам, с числами автора), result, note.
- numbers: все числа и диапазоны с условиями — name, value, cond, page.
- formulas: все формулы — expr, no (номер в книге или ""), page, vars (s — обозначение, m — смысл, u — единицы), note.
- tables: таблицы книги из единиц шага целиком — title, page, head (строка заголовков), rows, notes.
- bookTasks: задачи и вопросы книги из единиц шага — no, text, need (что нужно для решения, например «рис. 70»), page.
- glossary: новые понятия шага — term, en (английский термин, если знаешь, иначе ""), def (одна фраза), page.
- mistake: частая ошибка новичка по этой теме — wrong, right, page; ref — id подходящего заблуждения из списка ниже или "".
- data: мост к данным — input (что на входе), output (что получают), breaks (что в данных ломается). Пункт, которого нет в книге, начинай с «Гипотеза модели:».
- decision: если шаг про решение на данных — applies: true, features (признаки), rule (правило автора), conclusion (вывод на примере автора), counterexample; иначе applies: false и пустые поля.
- analogy: бытовая аналогия, text и limit — где она ломается. itAnalogy: аналогия из ИТ, text и limit.
- nowPractice: как это делают сейчас (вне книги, гипотеза модели) или "".
- inefficiency: где здесь ручной труд — applies, inputs, manualSteps, judgment, time («не указано в главе», если нет), errors.
- layers: mechanism (механизм, 1–3 фразы), practice (как применяют), nuances (условия и оговорки), deeper (куда копать дальше — только ссылки внутри книги или "").
- whyHere: одна фраза, почему шаг стоит здесь в пути.
- route: формат по маршрутизации — один из: шортс, длинное видео, интерактив, практикум на данных, карточки, текст; video_scores — по 0–2: time (изменение во времени), invisible (невидимое становится видимым), scale (скачок масштаба), counterintuitive, cause_effect; why — обоснование по типу трудности и баллам; template — шаблон сцены или "".
- figure: рисунок, который строится кодом по тексту: chain — цепочка из 2–6 коротких шагов (items, до 8 слов каждый) или matrix — таблица применимости (cols — столбцы, rows — строки, первый элемент строки — название, дальше значения best / yes / low / no). caption — что показано, alt — альтернативный текст.
- tasks: 2–4 задания с проверкой разных типов: single (options, answerIndex с 0), multi (options, answerIndexes), order (items в правильном порядке, 3–6 пунктов), blank (text с ___ и answerText — допустимые варианты ответа), calc (answerNumber, tol — допуск долей, например 0.02, unit; только если в шаге есть расчёт). У каждого задания id (t1, t2…), q, explain (одна фраза) и claim — id утверждения, из которого следует ответ.
- card: карточка повторения — front (вопрос), back (ответ одной-двумя фразами).
