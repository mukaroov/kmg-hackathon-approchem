Задача: разбить главу на путь из шагов для новичка.

Ниже — единицы главы: абзацы, заголовки, рисунки, таблицы, формулы, примеры и задачи. У каждой есть идентификатор, страница, тип и начало текста. Затем — полный текст главы с метками страниц.

Сделай:
- chapter: название курса для новичка (5–10 слов, о том, чему он научит), subtitle (автор, глава, параграфы), description (одна фраза), intro (два коротких абзаца: зачем это новичку и как устроен курс), book — выходные данные, если они есть в тексте; чего нет в тексте, оставь пустой строкой, не выдумывай.
- parts: части по разделам главы (параграфы, крупные заголовки), в порядке книги. У части title, short (2–5 слов), sub (одна фраза, что в ней).
- nodes внутри частей: шаги. Один шаг — одна идея, которую можно объяснить за 5–15 минут: обычно 3–12 единиц. Разбор примера автора, большая таблица или процедура могут быть отдельным шагом. Всего шагов: примерно {{targetNodes}}.
- n — сквозной номер шага с 1 по порядку. after — номера шагов, без которых этот шаг не понять (только более ранние).
- units — идентификаторы единиц, которые объясняет шаг. Каждая единица главы должна попасть ровно в один шаг: ничего не пропускай, включая рисунки, таблицы, формулы и задачи.
- difficulty.primary и difficulty.secondary — коды типа трудности: {{difficulty}}. secondary может быть пустой строкой.
- threshold: true, если без этой идеи дальше не понять ничего (пороговая идея).
- dataDecision: true у шага, где по данным принимается решение (хотя бы один такой шаг в главе, если в главе есть решение на данных).
- title — заголовок для новичка, 3–7 слов, без номеров параграфов; bookTitle — как это называется в книге (с номером параграфа или примера).
